## 1. Glosarium & Istilah Penting Adat/Pernikahan

Berikut istilah fundamental perpaduan tata laksana adat nusantara dan teknologi otomasi distribusi undangan modern:

### Uleman / Serat Katuran
Berasal dari bahasa Jawa dan Sunda kuno, bermakna surat panggilan kehormatan resmi untuk menghadiri hajatan sakral. Pada era digital, uleman bermutasi menjadi tautan personal bersandi unik yang memuat nama spesifik penerima demi memuliakan martabat sang tamu undangan.

### Rerembagan
Musyawarah keluarga besar adat untuk menyepakati daftar nama kerabat, sesepuh, tokoh masyarakat, dan rekan sejawat yang berhak menerima undangan secara berjenjang menurut tata krama kekeluargaan.

### Tedhak Siten / Pasang Tarub Digital
Metafora modernisasi penyiapan gerbang pernikahan. Jika tarub fisik menandai batas teritorial perhelatan, maka custom domain pribadi menandai identitas digital resmi perhelatan mempelai di ranah maya.

### Custom Shortlink Namespace
Penamaan domain pemendek tautan yang disesuaikan dengan jenama mempelai, berfungsi menaikkan rasio klik (Click-Through Rate), membangun kepercayaan (trust), serta menangkal algoritma anti-phishing WhatsApp.

### REST API Webhook Bridge
Jembatan protokol pemrograman yang menghubungkan sel data pada Google Spreadsheet dengan server URL shortener pihak ketiga secara asynchronous guna menghasilkan slug unik instan.

### URL Encoding Parameter
Konversi karakter nama tamu (termasuk spasi, gelar, tanda petik) menjadi format persentase heksadesimal (seperti %20 untuk spasi) agar tautan dinamis terbaca sempurna di semua peramban seluler.

## 4. Panduan Praktis Calon Pengantin Modern

Berikut tahapan teknis eksekusi pembuatan 1.000 tautan undangan personal menggunakan Google Spreadsheet dan API URL Shortener custom domain:

### Langkah 1: Penyiapan Struktur Spreadsheet
Buka Google Spreadsheet baru, lalu buat kolom-kolom berikut pada baris pertama:
- Kolom A: Nama Tamu (contoh: Bapak Joko Susanto & Ibu)
- Kolom B: Kategori Tamu (VIP, Keluarga, Teman Kantor, Sahabat)
- Kolom C: Nomor WhatsApp (format internasional: 628123456789)
- Kolom D: URL Mentah (Rumus: `="https://simfonicinta.my.id/nikah-mempelai?to=" & ENCODEURL(A2)`)
- Kolom E: URL Pendek Custom Domain (Hasil Automasi Script API)
- Kolom F: Template Pesan WhatsApp (Formula String Generator)

### Langkah 2: Menghubungkan Google Apps Script dengan API Shortener
Pilih menu Ekstensi > Apps Script pada Google Spreadsheet. Salin kode otomasi berikut:

```javascript
function generateShortUrls() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const lastRow = sheet.getLastRow();
  const apiKey = "MASUKKAN_API_KEY_SHORTENER_ANDA";
  const domain = "link.namapengantin.my.id"; // Custom domain terdaftar

  for (let i = 2; i <= lastRow; i++) {
    let longUrl = sheet.getRange(i, 4).getValue();
    let existingShortUrl = sheet.getRange(i, 5).getValue();

    if (longUrl !== "" && existingShortUrl === "") {
      let payload = {
        "long_url": longUrl,
        "domain": domain
      };

      let options = {
        "method": "post",
        "contentType": "application/json",
        "headers": {
          "Authorization": "Bearer " + apiKey
        },
        "payload": JSON.stringify(payload),
        "muteHttpExceptions": true
      };

      try {
        let response = UrlFetchApp.fetch("https://api.shortener.com/v1/shorten", options);
        let result = JSON.parse(response.getContentText());
        if (result.short_url) {
          sheet.getRange(i, 5).setValue(result.short_url);
        }
      } catch (err) {
        sheet.getRange(i, 5).setValue("ERROR");
      }
      Utilities.sleep(150); // Mencegah batas limit kuota request per detik
    }
  }
}
```

## 6. Tanya Jawab Komprehensif (FAQ)

### Pertanyaan 1: Mengapa sebaiknya menggunakan custom domain untuk URL Shortener undangan pernikahan?
Tautan dengan nama domain sendiri (contoh: link.rinadani.my.id) memberikan garansi autentisitas tinggi, menurunkan kecurigaan serangan siber (phishing), meningkatkan rasio buka tautan hingga 40%, serta memberikan kesan perhelatan yang terorganisir rapi dan eksklusif.

### Pertanyaan 2: Apakah pengiriman link undangan massal via WhatsApp berisiko pemblokiran nomor?
Ya, nomor WhatsApp pengirim berisiko terblokir apabila melakukan pengiriman pesan massal berkecepatan tinggi dengan isi pesan identik ke nomor-nomor yang belum saling simpan kontak. Solusinya: gunakan jeda waktu acak (delay 10-30 detik antar pesan), variasikan isi pembuka pesan, dan gunakan domain pendek resmi yang telah berstatus terpercaya.

### Pertanyaan 3: Bagaimana jika tamu undangan yang diinput mencapai lebih dari 1.000 nama?
Google Apps Script memiliki batas waktu eksekusi (execution limit) 6 menit per running pada akun standar. Untuk memproses lebih dari 1.000 data, jalankan skrip per kelompok data (batch processing sebanyak 200-300 baris per eksekusi) atau gunakan trigger waktu otomatis per beberapa menit hingga seluruh sel terisi.

### Pertanyaan 4: Apakah URL shortener gratisan seperti tinyurl atau is.gd cukup memadai?
Layanan pemendek tautan publik gratis dapat digunakan, namun rentan ditandai sebagai spam oleh WhatsApp atau peramban seluler. Selain itu, layanan publik tidak mendukung nama domain personal keluarga dan sewaktu-waktu dapat mengalami kendala server down di hari bahagia pernikahan.

### Pertanyaan 5: Apakah platform Simfoni Cinta mendukung impor data nama tamu langsung dari file Excel atau Spreadsheet?
