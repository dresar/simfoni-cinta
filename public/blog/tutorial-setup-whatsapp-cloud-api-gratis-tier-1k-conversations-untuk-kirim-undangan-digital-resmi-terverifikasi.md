## 1. Glosarium & Istilah Penting Adat/Pernikahan

Penggabungan teknologi API modern dengan ritual pernikahan adat memerlukan pemahaman terminologi budaya berikut:

*   **Ulem-Ulem**: Istilah bahasa Jawa halus (*Krama Inggil*) untuk surat undangan perkawinan. Secara etimologi berasal dari kata dasar *ulem* yang berarti panggil atau undang.
*   **Kintun Pawarta**: Wacana peradaban Jawa mengenai proses pengiriman kabar berita pesta perkawinan kepada sanak saudara dan kerabat jauh.
*   **Caraka**: Utusan resmi keluarga besar yang bertugas menyampaikan *ulem-ulem* secara lisan maupun tertulis dengan menjunjung etika kesopanan.
*   **Pawukon**: Sistem penanggalan tradisional berbasis 30 *wuku* untuk menentukan hari baik (*dino becik*) pengiriman undangan agar acara berjalan lancar.
*   **Sowan**: Tradisi mengunjungi kediaman sesepuh atau orang tua secara langsung untuk menyampaikan penghormatan sebelum undangan resmi dikirimkan.
*   **Buwuh / Navolging**: Tradisi nilai komunal berupa pemberian sumbangan, kado, atau tunai kepada pengantin sebagai bentuk solidaritas sosial.
*   **Rembag Karsa**: Musyawarah permufakatan antar dua keluarga besar untuk menyetujui daftar final tamu undangan dari kedua belah pihak.

### Langkah Teknis Confiugration WhatsApp Cloud API (Free Tier Meta)

Berikut adalah panduan teknis langkah demi langkah untuk mengaktifkan API resmi Meta secara gratis:

```
[Buat Account Developer Meta] ──> [Buat Meta App (Business)] ──> [Tambahkan Produk WhatsApp]
                                                                        │
[Kirim Undangan via cURL/API] <── [Buat Template Pesan] <── [Verifikasi Nomor HP Bisnis]
```

#### Langkah 1: Registrasi Portal Developer Meta
1. Buka laman `developers.facebook.com` dan login menggunakan akun Facebook aktif.
2. Klik tombol **My Apps** di pojok kanan atas, lalu pilih **Create App**.
3. Pilih tipe aplikasi: **Other** -> **Business**.
4. Masukkan nama aplikasi (contoh: `UndanganPernikahan-App`) dan masukkan email kontak aktif.

#### Langkah 2: Menambahkan Produk WhatsApp
1. Di dalam Dashboard App Meta, gulir ke bawah menuju daftar produk.
2. Temukan opsi **WhatsApp**, lalu klik **Setup**.
3. Pilih atau buat **Meta Business Account** (Akun Bisnis Meta).

#### Langkah 3: Mengambil Temporary Token dan Test Phone Number
 Meta menyediakan nomor penguji (*Test Phone Number*) dan `Temporary Access Token` (berlaku 24 jam) untuk tahap pengujian pengiriman pesan.

```bash
# Contoh Payload cURL Pengiriman Pesan WhatsApp API (Test Number)
curl -i -X POST \
  https://graph.facebook.com/v18.0/YOUR_PHONE_NUMBER_ID/messages \
  -H 'Authorization: Bearer YOUR_TEMPORARY_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "messaging_product": "whatsapp",
    "to": "6281234567890",
    "type": "template",
    "template": {
      "name": "hello_world",
      "language": {
        "code": "en_US"
      }
    }
  }'
```

#### Langkah 4: Registrasi Nomor HP Pernikahan Sendiri
Agar pesan terkirim atas nama pengantin, daftarkan nomor telepon asli:
1. Masuk ke menu **WhatsApp** -> **API Setup**.
2. Pada bagian **Step 5: Add Phone Number**, klik **Add Phone Number**.
3. Masukkan nama tampilan profil (*Display Name*), misal: `Pernikahan Budi & Ani`.
4. Masukkan nomor HP (pastikan nomor ini belum terdaftar di aplikasi WhatsApp Android/iOS reguler. Jika sudah terdaftar, hapus akun WhatsApp di HP terlebih dahulu).
5. Pilih verifikasi via **SMS** atau **Panggilan Telepon**, lalu masukkan kode OTP 6-digit.

#### Langkah 5: Membuat Template Pesan Undangan (Message Template)
Meta mewajibkan penggunaan template yang disetujui (*Approved*) untuk memulai percakapan ke tamu:
1. Buka Meta Business Manager -> **WhatsApp Manager** -> **Message Templates**.
2. Klik **Create Template**.
3. Pilih Kategori: **UTILITY**.
4. Nama Template: `undangan_pernikahan_resmi` (gunakan huruf kecil dan garis bawah).
5. Pilih Bahasa: **Indonesian (id)**.

```text
CONTOH DRAFT BODY TEMPLATE UNTUK APPROVAL META:

Yth. {{1}},

Tanpa mengurangi rasa hormat, kami mengundang Bapak/Ibu/Saudara/i untuk menghadiri acara pernikahan kami:

Pengantin: {{2}}
Hari/Tanggal: {{3}}
Lokasi: {{4}}

Info selengkapnya dan konfirmasi kehadiran (RSVP) dapat diakses melalui tautan digital resmi berikut:
{{5}}

Merupakan suatu kehormatan bagi kami apabila Bapak/Ibu/Saudara/i berkenan hadir dan memberikan doa restu.

Terima kasih.
```

6. Tambahkan variabel sampel (contoh: `{{1}}` = Budi Santoso, `{{2}}` = Ani & Budi, dst).
7. Klik **Submit**. Proses persetujuan otomatis oleh sistem AI Meta membutuhkan waktu antara 1 menit hingga 1 jam.

#### Langkah 6: Membuat Permanent System User Token
Temporary Token akan kadaluwarsa dalam 24 jam. Buat token permanen agar pengiriman pesan dari sistem dapat berjalan tanpa henti:
1. Buka **Meta Business Settings** (`business.facebook.com/settings`).
2. Masuk ke menu **Users** -> **System Users**.
3. Klik **Add**, isi nama System User (contoh: `SystemAdmin`), peran: **Admin**.
4. Klik **Add Assets**, pilih **Apps** -> Pilih `UndanganPernikahan-App` -> Aktifkan akses **Full Control**.
5. Klik **Generate New Token**.
6. Pilih App yang sesuai, beri centang pada dua izin (*permissions*) wajib:
   * `whatsapp_business_messaging`
   * `whatsapp_business_management`
7. Klik **Generate Token**. Simpan string token ini di tempat aman.

## 6. Tanya Jawab Komprehensif (FAQ)

### Pertanyaan 1: Apakah benar 1.000 percakapan pertama tiap bulan di WhatsApp Cloud API gratis 100%?
**Jawaban**: Ya. Meta memberikan kuota 1.000 *Service/Utility Conversations* gratis setiap bulan untuk setiap Akun Bisnis Meta (Meta Business Account). Jika jumlah tamu di bawah 1.000 orang, pengantin tidak dikenakan biaya sama sekali oleh Meta.

### Pertanyaan 2: Mengapa nomor WhatsApp saya harus keluar dari aplikasi HP reguler saat didaftarkan ke API?
**Jawaban**: Arsitektur teknis Meta memisahkan infrastruktur nomor seluler biasa (Consumer/Business App) dengan infrastruktur Cloud API. Satu nomor telepon hanya dapat aktif di satu platform. Jika ingin menggunakan Cloud API, nomor harus di-deregister dari aplikasi WhatsApp HP terlebih dahulu.

### Pertanyaan 3: Apa yang terjadi jika pesan dikirim ke nomor yang tidak terdaftar di WhatsApp?
**Jawaban**: Meta Graph API akan mengembalikan respon error ber-code `131026` (*Receiver is not a valid WhatsApp user*). Sistem automasi dapat langsung menandai nomor tersebut di spreadsheet untuk dikirimkan surat fisik atau dihubungi via panggilan seluler biasa.

### Pertanyaan 4: Mengapa template pesan saya ditolak (*Rejected*) oleh pihak Meta?
**Jawaban**: Meta menolak template yang mengandung unsur *hard selling*, promosi produk komersial pada kategori Utility, atau format parameter `{{x}}` yang tidak jelas. Pastikan kategori yang dipilih adalah **UTILITY**, bahasa disesuaikan dengan isi (Indonesian), dan tidak mengandung kata-kata sensitif.

### Pertanyaan 5: Bagaimana cara menggabungkan Cloud API dengan platform Simfoni Cinta?
**Jawaban**: Buat daftar nama tamu di platform Simfoni Cinta (`https://simfonicinta.my.id`) untuk mendapatkan link unik tiap tamu (contoh: `simfonicinta.my.id/to/budi`). Masukkan link unik tersebut ke dalam variabel `{{5}}` pada skrip pengiriman WhatsApp Cloud API yang sudah disiapkan.
