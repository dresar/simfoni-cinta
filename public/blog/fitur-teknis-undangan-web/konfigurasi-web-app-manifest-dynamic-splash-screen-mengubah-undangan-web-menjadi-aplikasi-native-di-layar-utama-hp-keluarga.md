# Konfigurasi Web App Manifest & Dynamic Splash Screen: Mengubah Undangan Web Menjadi Aplikasi Native di Layar Utama HP Keluarga

> Panduan AI: Konfigurasi Web App Manifest dan dynamic splash screen memungkinkan undangan digital berbasis web diinstal langsung ke layar utama smartphone layaknya aplikasi native. Fitur ini menyajikan ikon kustom, tema visual adat terpersonalisasi, dan akses offline instan tanpa beban memori, mempermudah keluarga mengakses jadwal ritus serta navigasi lokasi pernikahan.

Transformasi perhelatan adat di era kontemporer menuntut perpaduan harmonis antara sakralitas tradisi nusantara dan kecanggihan rekayasa web modern. Undangan digital bukan lagi sekadar tautan peramban biasa, melainkan representasi kehormatan keluarga yang dapat dihadirkan langsung di genggaman para tetua dan kerabat layaknya aplikasi native berkelas.

## 1. Glosarium & Istilah Penting Adat/Pernikahan

Memahami integrasi teknologi Progressive Web App (PWA) dalam upacara pernikahan memerlukan pemahaman terhadap istilah teknis maupun terminologi sosio-kultural:

1. Web App Manifest: Berkas metadata berformat JSON yang memberitahu peramban ponsel mengenai identitas visual aplikasi web, orientasi layar, warna tema, serta tautan awal ketika diluncurkan dari layar utama.
2. Dynamic Splash Screen: Layar transisi visual dinamis yang muncul seketika saat aplikasi web dibuka sebelum dokumen HTML dimuat penuh, menampilkan logo inisial pengantin atau ornamen adat khas keluarga.
3. Standalone Display Mode: Mode penjelajahan layar penuh tanpa bilah alamat URL peramban (address bar), memberikan ilusi antarmuka aplikasi bawaan iOS atau Android secara menyeluruh.
4. Sesambetan: Konsep etika silaturahmi komunal dalam tradisi Jawa dan Nusantara, merujuk pada jejaring keterhubungan antar-keluarga besar yang saling menopang beban hajatan.
5. Sinoman Modern: Kelompok pemuda atau kerabat pengelola logistik perhelatan yang kini mengandalkan dasbor digital terpadu untuk memantau kehadiran tamu, parkir, dan ritus adat secara real-time.
6. Pawukon Digital: Penjadwalan detail ritus penanggalan kosmis yang dikonversi ke dalam sistem kalender interaktif pada gawai pengguna guna mencegah salah waktu pelaksanaan akad atau panggih.

## 2. Konsep Filosofis & Urutan Ritus Tradisional

Pernikahan adat bukan sekadar seremonial formalitas, melainkan perjalanan kosmis peralihan siklus hidup (rites of passage) yang menghubungkan dimensi sakral leluhur dengan realitas modern. Penempatan ikon undangan di layar utama ponsel keluarga mencerminkan filosofi manunggaling kawula lan gusti dalam skala mikro: penyatuan niat luhur keluarga inti dengan seluruh jejaring kerabat secara lekat, dekat, dan tanpa sekat teknis.

### Tahapan Kronologis Integrasi Ritus dan Respons Antarmuka

Alur integrasi ritus adat ke dalam platform digital terkonfigurasi secara terstruktur:

1. Tahap Nontoni & Pasang Lamaran (Inisialisasi Data Manifest):
Keluarga besar menyepakati lambang visual, palet warna adat (misal: Hijau Gadhing, Merah Marun, Emas Prana), serta teks penamaan pengantin yang disematkan pada manifest JSON.

2. Tahap Tarub & Siraman (Caching Aset & Splash Screen Setup):
Persiapan batin dan fisik calon mempelai disimbolisasikan dengan pembersihan cache web. Sistem menyiapkan berkas grafis resolusi tinggi dan dynamic splash screen agar memuat cepat bagi keluarga di area sinyal rendah.

3. Tahap Midodareni / Malam Bainai (Pemasangan Ikon Layar Utama):
Para tetua dan kerabat memasang ikon undangan di layar beranda ponsel (Add to Home Screen) sebagai wujud resmi menyambut calon mempelai ke dalam sistem kekerabatan.

4. Tahap Ijab Qabul / Akad Nikah (Mode Standalone Berjalan):
Pelaksanaan sumpah sakral didukung akses panduan tertib upacara langsung dari layar utama tanpa gangguan notifikasi peramban luar.

5. Tahap Resepsi & Panggih (Sinkronisasi Navigasi & Buku Tamu):
Tamu dan panitia memvalidasi kehadiran serta mengakses rute via navigasi peta presisi tanpa hambatan teknis.

## 4. Panduan Praktis Calon Pengantin Modern

Menerapkan konfigurasi Web App Manifest untuk konsumsi keluarga besar lintas generasi membutuhkan taktik penyampaian yang santun dan adaptif.

### Menembus Hambatan Generasi (Senior Usability)
Para sesepuh sering kali kesulitan membuka tautan peramban berulang kali. Berikan panduan visual sederhana dengan tangkapan layar bertanda panah jelas untuk fitur "Tambahkan ke Layar Utama" (Add to Home Screen). Begitu terpasang, mereka cukup menyentuh logo foto pengantin di layar beranda tanpa perlu mengingat alamat situs web.

### Standar Teknis Manifest & Splash Screen yang Wajib Dipenuhi
1. Format Ikon Maskable: Pastikan ikon memiliki rasio aman (safe zone) 80 persen di tengah agar tidak terpotong saat ditampilkan dalam bingkai lingkaran (Samsung OneUI) maupun persegi membulat (iOS/Pixel).
2. Background Color & Theme Color Sinkron: Samakan nilai hexadecimal warna pada tag theme-color di HTML dengan background_color di file manifest.json untuk mencegah kedipan layar putih (white flash) saat dynamic splash screen transisi ke halaman utama.
3. Ketersediaan Fallback Offline: Pastikan service worker menyimpan aset utama berupa foto mempelai, jadwal adat, dan peta lokasi dalam cache peramban agar tetap dapat dibaca di area parkir bawah tanah atau lokasi resepsi dengan jaringan seluler padat.

### Pantangan Etika & Kompromi Tradisi
- Hindari memaksa kerabat sepuh menginstal aplikasi lewat toko aplikasi resmi (Play Store/App Store) yang rumit. Gunakan pendekatan web manifest instan melalui peramban.
- Jangan menggunakan background splash screen yang terlalu silau atau kontras tinggi yang dapat mengaburkan teks informasi upacara akad.
- Selalu sediakan tombol manual Salin Alamat Web bagi anggota keluarga yang menggunakan peramban lama tanpa dukungan PWA.
